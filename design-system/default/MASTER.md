# 退休攒钱计算器设计系统

> 产品和财务规则优先。本规范记录经 `ui-ux-pro-max` 检索后，针对中文个人财务 Web/H5 验证过的实施结论。自动建议的深色玻璃拟态、金融蓝和手写字体因违反产品方向而舍弃。

## 1. 设计原则与信息层级

三秒可读、温和可信、本地可控、渐进披露。概览顺序：退休时间 → 净资产/负债/目标/月结余 → 0 轴财富位置 → 时间拆解 → 趋势 → 情景模拟。台账：新增 → 筛选 → 列表。分析：趋势 → 支出/时间对比 → 表格。设置：核心参数 → 增长假设 → 备份隐私 → 危险操作。

## 2. 色彩 Token

背景 `#F5F6F2`；卡片 `#FFFFFF`；主色 `#326B4D`，hover `#285A40`，浅底 `#E8F2EC`；危险 `#A63F43` / `#FAECEC`；警示 `#8A5A20` / `#FBF2E3`；正文 `#18221C`，次级 `#59675F`，辅助 `#6F7C74`；边框 `#DDE4DF`。组件只使用 `variables.scss` 的语义 Token。

## 3. 字体、数字与间距

系统字体栈；页面标题 28–32/650，Hero 40–52/650，指标 21–27/650，移动端正文 16px，辅助 13px。金额使用 `tabular-nums`。4/8px 体系：4、8、12、16、20、24、32、40；卡片桌面 24px、手机 18px。

## 4. 形状、阴影与图标

圆角 8/12/16/20px；卡片 1px 边框与极弱阴影；Modal 使用中等阴影。统一 Lucide 线性图标，常规 18–20px、导航 20–21px；图标按钮命中区 44×44px并有 `aria-label`。

## 5. 组件

按钮最小高 44px，每屏一个主要动作。输入最小高 46px、可见 label、失焦校验，错误紧邻字段并关联 `aria-describedby`。Badge 含文字。Modal 桌面居中、手机 Bottom Sheet；ESC 关闭、循环焦点、关闭后返回触发器。状态提示不抢焦点。

## 6. 图表

趋势用折线/10% 浅面积；静态动态用横向条形；支出 ≤5 类用 Donut，>5 类改横向条形。主序列 `#3F7C5A`，目标 `#A66A32` 且为虚线，网格 `#E7ECE8`。显示单位、tap/click Tooltip、空态、摘要与数据表，不能只靠颜色或 hover。

## 7. 动效

fast 140ms、base 220ms、进度 450ms；只用 opacity/transform，缓动 `cubic-bezier(.2,.8,.2,1)`。不使用滚动表演动画；`prefers-reduced-motion` 下近乎即时。

## 8. 响应式

375/390/430：16px gutter、2 列指标、其余单列、Bottom Sheet；768：隐藏 Sidebar；1024：232px Sidebar、指标 2 列；1280–1920：指标 4 列，主内容最大 1280px。移动底栏预留安全区和内容空间；页面无横向滚动。

## 9. 可访问性

正文对比 ≥4.5:1；焦点环 3px；路由后焦点进入 main；提供跳过导航；状态使用文字+颜色；表单有 label/字段错误；图表有文本摘要；键盘完成主要操作；删除、导入覆盖、清空需要确认。

## 10. 反模式

禁止金融蓝/金色、玻璃拟态、霓虹、金币钞票、Emoji 导航、颜色单独表达状态、placeholder 代替 label、hover-only、桌面页面直接缩小、无意义动画、3D/彩虹图表、组件内散落色值。

## 四个核心页面

- 概览：Hero 是唯一视觉主角。Desktop 4 列指标与双列预测/记账；Mobile Hero 与操作纵向、指标 2 列。不可达时给改善路径，趋势为空时给明确空态。
- 台账：Desktop 顶部新增与横向筛选；Mobile 筛选 2 列、列表操作换行。删除说明资产回滚并反馈；空态提供记录第一笔。
- 分析：趋势通栏，支出/对比双列；Mobile 全部单列并减少刻度。图表支持点击查看，提供空态、摘要或预测表替代。
- 设置：字段按 Section Card 分组，Desktop 2 列、Mobile 1 列；校验通过后防抖自动保存。备份与危险区分隔，覆盖和清空均明确确认。
