# 计算口径

## 单位和舍入

核心计算统一使用整数“元”，UI 可显示元或万元。输入万元时用 `Math.round(万元 × 10000)` 转成整数元。逐月现金流、还款、投资收益、通胀目标和工资更新均在该步骤结束时四舍五入到整数元；因此长期复利不会无约束累积二进制浮点尾差。百分比在配置中用小数表示，如 2% 为 `0.02`。

## 基础定义

- 当前净资产 = 当前总资产 − 当前剩余负债。
- 退休目标是目标净资产。达标条件为净资产不小于当月退休目标。
- 初始净资产已经达标时立即返回 0 个月。
- 月基础现金流 = 月工资 + 月副业收入 − 月固定消费。
- 真实月收益率 = `(1 + 年化收益率)^(1/12) − 1`，月通胀率同理。

## 动态逐月顺序

第 0 月先检查是否达标。此后每月严格执行：

1. 使用本月工资、期初资产、负债和目标。
2. 加月工资及副业，减月固定消费。
3. 仅在第 12、24、36……个月加入年终奖并扣除年度大额消费。
4. 只要剩余负债大于 0 就处于负债阶段。实际还款为计划还款、剩余负债、当月非负可支配现金流和可用资产的最小值。还款令资产和负债等额减少，因此不会再次降低净资产。计划还款为 0 或长期无可用现金时负债不减少。
5. 计算计息前净资产，仅 `max(计息前净资产, 0)` 参与投资收益；收益写入资产，不改变负债。负收益率可令正净资产产生负收益。
6. 开启通胀时只提高退休目标一个月，不再提高消费，避免重复通胀。
7. 保存资产、负债、净资产、目标、本金、收益和本月事件快照。
8. 检查达标，达到即停止。
9. 每满 12 个月后按工资增长率更新工资，供下一个月使用。负增长率受到输入范围约束但允许使用。

最多计算 1200 个月。超过上限、负债无法清偿或现金流无法使目标达成时返回 `reachable: false`、原因码及最后快照，不返回 NaN、Infinity 或 undefined。

`totalPrincipal` 仅表示模拟期间收入减消费形成的累计净投入（含年度事件），不含初始资产和投资收益；`totalContributedCapital` 为初始资产加累计净投入。历史台账描述已经发生的交易，只修改当前资产，不会再加入未来预测。

## 静态基准

静态模型不计算投资收益、工资增长和通胀；年终奖和年度消费按 12 个月均摊。仍先判断负债可否按计划和现金流清偿，再计算财富积累。计划还款为 0、负债无法清偿、财富阶段净结余不为正或超过 1200 个月时返回不可达。

## 模型限制

第一版没有债务利息，因为没有各笔贷款的利率和摊还结构。展示结果是现金流规划，不是贷款摊销计划。所有资产共用一个年化收益假设，不模拟市场波动、税费和交易成本。
